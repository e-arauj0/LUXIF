Código

O código roda no Arduino Uno: lê o LDR, troca de faixa sozinho, calcula o valor em lux e mostra no display. Ao ligar, o display toca uma animação de abertura.

Baixar o código

Como gravar no Arduino

  1. Instale a Arduino IDE.
  2. Abra o arquivo luxif.ino e escolha a placa Arduino Uno e a porta.
  3. Clique em Carregar.
  4. Ao ligar, toca a animação de abertura (cerca de 2 segundos) e depois o valor em lux aparece no display. Ele também aparece no Monitor Serial, em 9600 baud.

Bibliotecas

  • Adafruit SSD1306: controla o display OLED.
  • Adafruit GFX: desenha textos e linhas no display.

Instale as duas pelo Gerenciador de Bibliotecas da Arduino IDE. A biblioteca Wire, usada na comunicação com o display, já vem com a IDE.

Os 10 quadros da animação ocupam cerca de 10 KB dos 32 KB de memória de programa do Arduino Uno. Por isso o código completo abaixo mostra só o começo deles; os bytes estão no arquivo para baixar.

Partes do código

FunçãoO que faz
setup()Roda uma vez quando o Arduino liga: prepara os LEDs, escolhe a primeira faixa, liga o I²C (Wire.begin()) e o display e toca a animação de abertura. Se o display não responder, avisa no Monitor Serial ("SSD1306 allocation failed") e para.
loop()Roda sem parar: lê o sensor, troca de faixa se precisar e, se a leitura estiver boa, calcula e mostra o lux.
rodarAnimacaoBoot()Mostra, um por vez, os 10 quadros da animação de abertura, que ficam guardados na memória de programa (PROGMEM). Roda uma única vez, no setup().
selecionarFaixa()Liga o pino de uma faixa e o seu LED, e desliga os outros.
lerMedia()Lê o pino A0 dez vezes e devolve a média, para diminuir o ruído.
calcularLux()Calcula a resistência do LDR e a converte em lux pela curva do sensor.
atualizarOLED()Escreve no display o valor em lux, a faixa em uso, a leitura bruta (ADC) e, no rodapé, as quatro faixas com a ativa entre colchetes. Se a leitura passar de 920 na faixa de 470 kΩ, não há resistor maior para tentar, e o display mostra "Excedido" no lugar do valor.

A ideia principal: a cada volta do loop(), se a leitura passar de 920 (escuro demais para a faixa), o código pula para um resistor maior; se ficar abaixo de 100 (claro demais), pula para um menor. Só quando a leitura está entre os dois limites o valor em lux é calculado.

O que você pode ajustar

O código foi escrito para ser fácil de adaptar. As constantes que você mais vai querer mudar ficam no começo do arquivo:

ConstantePara que serve
A e GAMAA curva do seu LDR. Ajuste depois de comparar com um luxímetro de referência, como explicado em Como funciona.
RESISTORES e NOMES_FAIXAOs valores dos resistores de referência. Se usar outros, mude os dois vetores.
LIMITE_ALTO e LIMITE_BAIXOAs leituras (0 a 1023) que disparam a troca de faixa.
PINOS_FAIXA e PINOS_LEDOs pinos dos resistores de referência e dos LEDs, se você ligar de outro jeito.
SCREEN_ADDRO endereço I²C do display: 0x3C na maioria dos módulos, 0x3D em alguns.

Código completo

// baixar bibliotecas Adafruit SSD1306
// Adafruit GFX

#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>

#define SCREEN_WIDTH  128
#define SCREEN_HEIGHT 64
#define OLED_RESET    -1
#define SCREEN_ADDR   0x3C

Adafruit_SSD1306 display(SCREEN_WIDTH, SCREEN_HEIGHT, &Wire, OLED_RESET);

// Animação de abertura: 10 quadros (frame0 a frame9), cada um com 1024 bytes
// de um desenho de 128x64 pixels. Os bytes foram omitidos aqui; eles estão
// no arquivo para baixar.
const uint8_t PROGMEM frame0[1024] = { /* ... */ };
const uint8_t PROGMEM frame1[1024] = { /* ... */ };
/* ... frame2 a frame9 ... */

// Array de ponteiros e número de frames visíveis para todo o código
const uint8_t* const frames[] = {
  frame0, frame1, frame2, frame3, frame4, 
  frame5, frame6, frame7, frame8, frame9
};
const uint16_t numFrames = 10;

// Pinos
const int PINO_LDR = A0;
const int PINOS_FAIXA[4] = {2, 3, 4, 5};    // Pinos dos resistores de referência
const int PINOS_LED[4] = {8, 9, 10, 11};      // Pinos dos LEDs indicadores de faixa

// Faixas e Valores de Resistores
const long RESISTORES[4] = {1000, 10000, 100000, 470000};
const char* NOMES_FAIXA[4] = {"1k", "10k", "100k", "470k"};

// Limites para troca automática de faixa (Auto-Range)
const int LIMITE_ALTO = 920;
const int LIMITE_BAIXO = 100;

// Curva do LDR: R = A * lux^(-GAMA). Ajustar conforme calibração.
const float A = 75000.0;
const float GAMA = 0.7;

int faixaAtual = 1;

void selecionarFaixa(int novaFaixa) {
  for (int i = 0; i < 4; i++) {
    pinMode(PINOS_FAIXA[i], INPUT);
    digitalWrite(PINOS_LED[i], LOW);
  }

  faixaAtual = novaFaixa;
  pinMode(PINOS_FAIXA[faixaAtual], OUTPUT);
  digitalWrite(PINOS_FAIXA[faixaAtual], HIGH);
  digitalWrite(PINOS_LED[faixaAtual], HIGH);
  delay(10);
}

int lerMedia() {
  long soma = 0;
  for (int i = 0; i < 10; i++) {
    soma += analogRead(PINO_LDR);
  }
  return soma / 10;
}

float calcularLux(int leitura) {
  if (leitura >= 1023) return 0;
  if (leitura < 1) leitura = 1;

  float resistenciaLdr = RESISTORES[faixaAtual] * (float) leitura / (1023.0 - (float)leitura);
  return pow(A / resistenciaLdr, 1.0 / GAMA);
}

// FUNÇÃO DA ANIMAÇÃO DE BOOT (Roda apenas uma vez)
void rodarAnimacaoBoot() {
  for (uint16_t i = 0; i < numFrames; i++) {
    display.clearDisplay();
    display.drawBitmap(0, 0, frames[i], 128, 64, SSD1306_WHITE);
    display.display();
    delay(143); // Velocidade de transição entre os quadros
  }
  delay(400); // Pausa final após a animação acabar
}

// Exibe os resultados na OLED
void atualizarOLED(float lux, int leitura) {
  display.clearDisplay();
  display.setTextColor(SSD1306_WHITE);

  // Título e Faixa
  display.setTextSize(1);
  display.setCursor(0, 0);
  display.print(F("LUXIF - AUTO RANGE"));

  display.drawLine(0, 10, 127, 10, SSD1306_WHITE);

  // Status da Faixa Atual e ADC
  display.setCursor(0, 14);
  display.print(F("Faixa: "));
  display.print(NOMES_FAIXA[faixaAtual]);
  display.print(F(" | ADC: "));
  display.print(leitura);

  // Valor principal em Lux ou estado de limite excedido
  display.setCursor(0, 28);
  if (leitura > LIMITE_ALTO && faixaAtual == 3) {
    display.setTextSize(2);
    display.println(F("Excedido"));
  } else {
    display.setTextSize(3);
    display.print(lux, lux < 10.0 ? 3 : (lux < 100.0 ? 2 : 0));
    display.setTextSize(1);
    display.println(F(" Lux"));
  }

  // Rodapé com indicadores visuais de faixa ativa
  display.setTextSize(1);
  display.setCursor(0, 54);
  for (int i = 0; i < 4; i++) {
    if (i == faixaAtual) {
      display.print(F("["));
      display.print(NOMES_FAIXA[i]);
      display.print(F("] "));
    } else {
      display.print(F(" "));
      display.print(NOMES_FAIXA[i]);
      display.print(F("  "));
    }
  }

  display.display();
}

void setup() {
  Serial.begin(9600);
  Wire.begin();

  for (int i = 0; i < 4; i++) {
    pinMode(PINOS_LED[i], OUTPUT);
  }
  selecionarFaixa(faixaAtual);

  // Inicializa o display OLED
  if (!display.begin(SSD1306_SWITCHCAPVCC, SCREEN_ADDR)) {
    Serial.println(F("SSD1306 allocation failed"));
    while (true);
  }

  display.setRotation(0);
  display.clearDisplay();
  display.display();

  // 👉 A ANIMAÇÃO É CHAMADA AQUI APENAS UMA VEZ NO INÍCIO
  rodarAnimacaoBoot();
}

void loop() {
  int leitura = lerMedia();

  // Leitura alta: escuro demais para esta faixa, usa resistor maior
  if (leitura > LIMITE_ALTO && faixaAtual < 3) {
    selecionarFaixa(faixaAtual + 1);
    return;
  }

  // Leitura baixa: claro demais para esta faixa, usa resistor menor
  if (leitura < LIMITE_BAIXO && faixaAtual > 0) {
    selecionarFaixa(faixaAtual - 1);
    return;
  }

  float lux = calcularLux(leitura);

  // Atualiza a tela OLED com as leituras do luxímetro
  atualizarOLED(lux, leitura);

  // Monitor Serial
  Serial.print(F("Faixa: "));
  Serial.print(NOMES_FAIXA[faixaAtual]);
  Serial.print(F(" | ADC: "));
  Serial.print(leitura);
  Serial.print(F(" | Lux: "));
  Serial.println(lux);

  delay(200);
}

Extensão opcional: versão com Wi-Fi (ESP32)

Esta parte foi acrescentada por causa de um projeto de extensão e não é necessária para o luxímetro. Para usar a página Internet (ESP32), existe uma versão do código para o ESP32. Ela segue a mesma lógica, com estas diferenças:

  • usa os pinos do ESP32 (veja a tabela em Componentes);
  • a leitura vai de 0 a 4095, então os limites passam a ser 400 e 3700; o rodapé do display mostra o endereço IP em vez das faixas;
  • conecta-se ao Wi-Fi e publica cada leitura, no formato {"lux":523.4,"percentage":100,"faixa":1}, num servidor MQTT público, de onde o site a recebe pela internet;
  • também aceita conexões direto pela rede local (WebSocket em ws://IP/ws, porta 80, o mesmo endereço do servidor ESP-IDF do Vinícius), para usar sem internet. O site envia a mensagem conectado ao abrir a conexão, como o servidor dele espera.

Para gravar, instale a placa esp32 (da Espressif Systems) no Gerenciador de Placas e, no Gerenciador de Bibliotecas, as bibliotecas PubSubClient, de Nick O'Leary (MQTT), e WebSockets, de Markus Sattler (rede local), além das duas do display. Antes de carregar, troque nome-da-rede e senha-da-rede pelos dados do seu Wi-Fi.

Ela foi escrita antes das últimas mudanças da versão do Arduino: não tem a animação de abertura, e o display mostra "Mto Escuro" e "Mto Claro" em vez de "Excedido".
